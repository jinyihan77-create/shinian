### 🔴 3. 语音按钮"不好用"的真实原因

你说"那个声音按钮我觉得不好用"——**我实测复现了**：

点击"说给拾念听"后：
- `aria-label` 从 `开始口述记录` → **点击后仍是 `开始口述记录`**（状态没变化）
- 按钮 DOM 没有任何变化（`afterHtmlChanged: false`）
- 页面新增一行提示：**"麦克风权限未开启，请允许后重试"**
- 没有进入"聆听中"状态（`listeningStatePresent: false`）

**根因**（`src/components/studio-ui.tsx:159`）：
```js
recognition.onerror = event => { setRecording(false); setMessage(event.error === "not-allowed" ? "麦克风权限未开启，请允许后重试" : ...); };
```

问题在于：**按钮点击后立刻 `setRecording(false)`，所以用户看到的是"点了没反应 + 一行小字"**。在还没授权麦克风的浏览器里，第一次点击必然失败，而按钮没有任何视觉反馈引导用户去授权。这不是 bug，是**交互设计问题**——第一次点击应该触发权限申请并明确提示。

### 🟡 4. 手机端顶部同步指示器：文字被隐藏，只剩一个小圆点

**证据**：`.sync-indicator` 按钮实际宽 **28px**，里面：
- 状态圆点 `.sync-dot` 宽 6px（可见）

**后果**：手机端右上角只有一个孤立的小圆点，用户不知道那是什么、也不知道同步状态。`aria-label` 里其实是有完整信息的（"已同步 02:26"），但视觉上丢了。

**截图对照**：`final-mobile-topright.png`（放大 4 倍）、`mobile-workspace.png`

## 三、一个只有"真人访问"才能发现的坑

### ⚠️ 腾讯云测试域名中间页拦住了所有访问者

**实测**：直接打开线上地址，**先出现一个「风险提醒」中间页**：

> 当前域名 … 是由腾讯云 CloudBase 提供的测试域名，仅供开发测试使用，内容可能处于未审核状态
> 请谨慎浏览，请勿泄露个人信息…
> 环境ID：echo-77-d3gm5g3t081337d79
> **[确定访问 (3s)]** ← 要等 3 秒倒计时才可点

**这意味着**：你发给任何人的链接，对方都会先看到这页"内容可能处于未审核状态"的警告。做视频展示时会拍到它；如果给面试官或朋友看，观感会打折扣。

**解法**（按代价排序）：
1. 在 CloudBase 控制台绑定自己的域名（有备案域名才行）
2. 开通"静态网站托管"用默认域名（部分套餐无此提示）
3. 视频里剪掉这一段，或把它当作"真实的部署过程"素材保留

> 这一条已记入记忆，避免以后误判成网站故障。
