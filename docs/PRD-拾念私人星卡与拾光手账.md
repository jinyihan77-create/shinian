# 拾念私人星卡与拾光手账 PRD

版本：2026-09-23  
状态：规划稿，尚未进入开发  
产品定位：只服务一个人的私人灵感、日常与关系记忆系统。

## 1. 这次要解决什么

当前“拾念”已经能记录念头、来源、理解与每日吊牌，但日常生活、照片和亲密关系仍散落在文字记录里。新的版本要把这些内容连接成一条自然的私人流程：

1. 白天随手留下想法、照片、印象深刻的事情，以及和恋人有关的片段。
2. 当天摘星时，根据真实记录生成今日回响、白羊座的今日星象灵感，以及“白羊 × 水瓶”的关系提示。
3. 摘星完成后自动生成当天的手账草稿，不再要求额外整理一次。
4. 每日手账按月装订成不同封面的书，放回一个可浏览的私人书架。

“回声屿”继续保存可反复思考的内容；“拾光簿”保存生活发生过的事情。两者可以互相引用，但不混成一个列表。

## 2. 产品架构

主导航调整为四个稳定入口：

| 入口 | 用途 | 默认动作 |
| --- | --- | --- |
| 记录 | 捕捉此刻的文字、语音、照片 | 继续输入 |
| 回声屿 | 检索念头、闪卡与待办 | 提问式搜索与回看 |
| 拾光簿 | 浏览每日手账、照片与月度书册 | 打开最近一本 |
| 设置 | 私人账号、星座偏好、备份 | 管理资料 |

每日摘星从“设置”移到“记录”页下方的今日区域。设置页不再承担日常操作。

## 3. 记录页：一个输入框，三种去向

保持“此刻，想记下什么？”为唯一主输入框，不增加一排复杂分类。用户开始输入或加入照片后，只显示三个轻量上下文按钮：

- 普通念头：默认状态，进入回声屿。
- 今日片刻：进入当天手账素材。
- 和 TA：进入当天手账，同时参与关系卡生成。

照片入口使用单独的图片图标，可多选、拖入或从手机相册选择。照片上传后先显示本地缩略图和真实上传状态；上传失败不能显示“已保存”。

一条内容可以同时属于“灵感”与“今日片刻”，系统通过引用关联，不复制两份正文。

## 4. 今日星卡：保留吊牌，再增加一张伴生卡

原有星空吊牌继续作为主卡，不把所有信息挤到一个牌面上。

### 4.1 主吊牌

- 正面：今日心情、从当天记录提取的一句话、白羊座小型星座符号。
- 背面：累计天数、连续天数、日期。
- 摘下一颗星后自动保存；展开“调整这张牌”时暂停自动保存。

### 4.2 “羊与瓶”伴生卡

主吊牌后方露出一张较窄的半透明伴生卡，横向轻扫或点击后展开：

- 白羊今日：行动能量、情绪提醒、适合做的一件小事。
- 水瓶回声：理解恋人当日状态的一句提醒。
- 两人的今天：只从标记为“和 TA”的真实记录中提取一条关系片段。
- 留一句给 TA：用户可以保留、修改或隐藏，不自动发送给任何人。

星座内容在 AI 未接通时显示“今日星象灵感尚未生成”，不能用固定演示文案伪装成当天结果。首版将它定位为反思提示，不宣称可预测现实事件。

### 4.3 生成触发

1. 打开今日区域。
2. 摘下一颗星。
3. 系统生成并保存主吊牌、伴生卡和当日手账草稿。

默认流程只有两步。生成失败时保留摘下的材质与用户文字，并提供一次明确重试。

## 5. 拾光簿：独立于零碎想法的私人相册

### 5.1 书架首页

- 一本书代表一个月，每天是一页，不为每一天单独造一本书。
- 书脊显示月份、当月记录天数和一枚代表色。
- 每月封面从当月照片、心情和关键词中生成，材质可为磨砂玻璃、珠光纸、夜光织物、淡彩胶片。
- Depth Image 暂不安装。后续仅评估用于月度封面或用户明确选中的重点照片，为单张照片增加克制的景深响应。
- 桌面端书本有轻微景深和抽出动作；手机端使用横向滑动与吸附，不依赖悬停。

### 5.2 每日手账页

每天的页面由以下区域组成：

1. 今日标题：从当天内容提取，可直接修改。
2. 三个片刻：优先使用用户标记的重要事件。
3. 照片拼贴：1 至 6 张，自适应布局，不裁掉主体。
4. 我的回响：当天最重要的一条想法或听后感。
5. 和 TA：当天存在关系记录时才出现。
6. 今日星卡：嵌入主吊牌的缩略图，可翻面查看天数。
7. 一句收尾：用户原话优先，AI 只负责压缩和编排。

页面使用“手账纸张 + 半透明胶片 + 少量手写批注”的组合，不做纯白纸板，也不把每一块都做成卡片。

### 5.3 自动生成规则

- 摘星后立即建立或更新当天草稿。
- 当天后来又增加记录时，手账显示“新增 2 个片刻”，由用户决定是否重新整理。
- 用户手动修改过的段落不会被后续自动生成覆盖。
- 没有照片时使用文字排版，不生成虚构图片。
- 没有“和 TA”记录时隐藏关系版块，不编造互动。
- 所有生成文字都保留引用来源，可以点回原始记录。

### 5.4 Depth Image 使用边界

- 一屏最多出现一处 Depth Image，不能同时驱动多张图片。
- 只允许出现在“拾光簿”的月度封面或重点照片查看状态。
- 不用于记录主页、回声屿普通卡片列表、闪卡列表和摘星吊牌。
- 移动端必须支持静态降级；关闭动态效果后仍能完整查看照片和文字。
- 接入前先验证首屏速度、触摸滚动、耗电和低性能设备表现；未达到要求时继续使用静态封面。

## 6. 私人资料与数据结构

### 6.1 个人偏好

新增私人偏好资料：

- 我的星座：白羊座。
- 恋人的星座：水瓶座。
- 关系称呼：默认“TA”，可修改。
- 星象文案语气：温柔、直接、克制三选一。
- 是否在每日手账中显示关系内容。

这些资料只保存在私人账号中，不出现在公开预览或分享元数据里。

### 6.2 新增数据对象

`moments`：每日片刻，保存文字、类别、发生日期、关联灵感和关系标记。  
`media_assets`：照片原图、缩略图、尺寸、上传状态和拍摄时间。  
`daily_journals`：每日手账草稿、来源片刻、用户修改状态、生成版本。  
`journal_books`：月度书册、封面材质、排序和月份统计。  
`daily_companion_cards`：白羊星象、水瓶提示、关系回响和对应来源。

照片必须使用私人对象存储并与账号权限绑定；数据库只保存资产标识和元数据，不能把大图塞进浏览器本地存储。

## 7. AI 生成边界

AI 输入仅包含当天被选中的记录、用户星座偏好和必要日期，不默认读取整个资料库。

AI 输出必须是结构化结果：

- 今日情绪与一句回响。
- 白羊今日的三项反思提示。
- 白羊 × 水瓶的一条相处建议。
- 当天手账标题、片刻排序与收尾句。
- 每个生成段落对应的来源记录 ID。

AI 未配置、超时或返回格式错误时，系统只使用用户原文生成基础手账，并明确显示“星象与整理尚未生成”。

## 8. 配色升级

整体从接近黑色的暗紫改为“莓果夜色 + 亮粉微光”。紫色保留为阴影和空间深度，粉色成为主要发光色。

| 用途 | 建议色 |
| --- | --- |
| 页面底色 | `#18121E`、`#211727` |
| 抬高表面 | `#2A1D31`、`#34223A` |
| 主粉色 | `#FF91BD` |
| 花瓣粉 | `#F6B8D1` |
| 珠光白 | `#FFF4FA` |
| 亮紫 | `#B49BDC` |
| 淡紫 | `#D8C5F0` |
| 冰蓝辅助 | `#BFDDEB` |
| 暖金点缀 | `#F2D29E` |

调整规则：

- 大面积背景至少提升一个明度层级，减少纯黑区域。
- 主按钮和当前状态使用亮粉，不再让暗紫承担主要操作。
- 玻璃面板提高到 14% 至 24% 的可见表面亮度，并保留细边缘高光。
- 不同书册、票根和星卡允许使用粉、紫、蓝、金的稳定组合，避免全站单色。
- 正文与背景保持清晰对比；发光只作用于边缘和图标，不糊化文字。

## 9. 关键交互标准

- 常用流程单手可完成，点击目标不小于 44px。
- 记录、上传和生成都有草稿状态，退出页面后不丢输入。
- 手机端不使用必须悬停才能发现的操作。
- 书架动效只影响书本，不推动标题和导航位置。
- 页面翻动、吊牌物理效果和星光动画在低性能设备自动降级。
- 开启“减少动态效果”后使用淡入与静态材质，功能保持完整。
- 自动生成永远不覆盖用户已手动修改的段落。

## 10. 夜间整理与 AI 润色（规划）

这个流程主要服务 Apple Watch 或备忘录一次贴入的大段口述。系统先把原文完整保存，再提供整理，不能在用户仍在表达时自动改写。

1. 用户贴入或导入大段文字，页面先显示“原文已接住”。
2. 停止输入 12 秒后，只轻声询问“说完了吗？”，不自动调用 AI。
3. 用户明确点击“我说完了，帮我整理”后，才开始润色。
4. 整理动效表现为原文中的微光逐句聚拢，依次形成主题、原话摘录和行动线索；动效不能遮住原文。
5. 结果提供“原文 / 整理后”切换和逐段差异，接受前永远保留原文。
6. AI 未接通、超时或失败时，明确显示未整理，不能伪装成功。

## 11. 七七的个人识别（规划）

数字 7 作为克制的个人签名，而不是新的装饰主题：

- 星卡、手账书脊和票据编号可使用 `07` 或 `Q7` 小签名。
- 连续七天记录时，在记录页长出一组七点星轨；中断不会惩罚或清零已有记忆。
- 每周出现一次“过去的七七想问现在的七七”，问题只引用真实旧记录。
- 不在每个按钮、标题和背景里重复数字 7，避免视觉噪音。

## 12. 每天愿意打开的理由（规划）

- 完成当天第一条记录后，直接在当前页面露出“一键摘星”，不再要求进入设置页。
- 记录页显示“今晚留下的第 3 个片刻”这类轻反馈，不用焦虑式连续打卡。
- 回声屿首页每天只浮出一个来自过去的问题，点开才展开来源。
- 摘星保持一次动作完成；心情和金句优先根据当天原话生成，用户只在需要时调整。
- 每七天形成一段可回看的星轨或小册页，让积累带来变化，又不增加每日任务。

## 13. 本轮边界

本文中的恋爱内容、白羊与水瓶伴生卡、照片相册、拾光簿、AI 夜间润色和数字 7 成长机制目前全部处于规划状态，尚未接入正式产品。本轮只实施记录标题动效、语音反馈、回声屿命名、提问式搜索和待办交互澄清。

## 14. 实施顺序

### 第一阶段：先把每天用得顺手

- 提亮全局颜色，建立粉色主交互与紫色空间层级。
- 导航新增“拾光簿”，摘星入口移到记录页。
- 增加白羊、水瓶与关系显示偏好。
- 记录时支持“今日片刻”和“和 TA”轻量标记。

### 第二阶段：真实相册与手账

- 接入私人照片上传、缩略图和跨设备同步。
- 建立每日手账与月度书册数据。
- 完成书架、每日页面、照片拼贴和原始记录回链。
- 摘星后自动建立当天手账草稿。

### 第三阶段：AI 与星象伴生卡

- 接入真实 AI 服务，生成结构化每日回响与手账。
- 加入白羊今日与白羊 × 水瓶伴生卡。
- 增加失败降级、来源标记、重新生成与手动锁定。

### 第四阶段：完整验收

- 使用真实私人账号在手机与电脑间验证文字、照片和手账同步。
- 验证连续七天记录、跨月生成书册、照片上传失败、AI 不可用与手动编辑保护。
- 检查 360×800、390×844、1280×720、1440×900 四种视口。

## 15. 完成标准

- 从记录一个日常片段到生成当天手账，不超过一次上下文选择和一次摘星。
- 念头、日常、照片与关系内容边界清楚，又能在手账页自然汇合。
- 白羊与水瓶内容来自真实配置；AI 未接通时不显示伪造运势。
- 每张照片真实保存、可跨设备查看、可从手账回到原始片刻。
- 书架在手机上可顺畅滑动，打开页面不遮挡文字或导航。
- 整体明显比当前更亮，粉色成为第一视觉信号，紫色只负责深度与夜色。
