# 拾念 · 本地模式说明

## 启动

双击项目根目录的 `启动灵感回声.cmd`，等待终端显示启动完成后，打开：

`http://localhost:3000`

也可以在项目目录运行 `npm run dev`。本地模式不需要登录，数据只属于这台电脑。

## 数据位置

正式记录、AI 整理结果、行动票和打卡数据保存在：

`private-data/pglite/`

这个目录已经被 Git 忽略，不会进入提交。不要在服务运行时直接编辑其中的文件。

## 备份与换电脑

在“账号与设置”中点击“导出完整备份”，保存生成的 JSON 文件。恢复时使用同一页面的备份恢复入口，并逐份确认导入结果。

换电脑时可以直接复制整个 `private-data/` 目录，也可以使用导出的 JSON 备份。复制目录前先关闭本地服务；复制后放回项目根目录，再启动即可。

## AI 状态

本地模式不自动购买或开通任何 AI 服务。没有配置 `OPENAI_API_KEY` 时，整理、来源识别、闪卡润色和 AI 清理会明确提示“AI 未配置”，但记录、编辑、检索、闪卡、行动票和打卡仍然可用。

## 地址与未来切换

`.env.local` 保留 `APP_ORIGIN=http://localhost:3000`，用于本地来源校验；`ECHO_LOCAL_MODE=1` 开启本地数据通道，腾讯云配置项保持注释而不删除。腾讯云环境只暂时隔离，原环境和数据保留，预计 2026-10-22 新周期恢复后作为备用；本地模式不会删除、重置或调用它。

如果未来需要多人访问，需要重新设计认证、数据库、备份和部署方案，再切换 `src/lib/server/supabase.ts` 的数据客户端与对应环境变量。不要直接打开旧腾讯云部署脚本；迁移手册目前只作为历史参考。
