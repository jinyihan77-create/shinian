# 灵感回声

> 2026-09-25 起腾讯云环境已因额度超额被隔离，本文件记录的地址当前不可访问。

中文个人灵感资料库：记录零碎想法，补充来源，用 AI 整理，再用自己的话写一次，日后按关键词找回。

本项目现在是纯本地单人应用：网站运行在本机，数据保存在项目内的 `private-data/pglite/`。腾讯云环境因额度周期暂时隔离，保留原环境和数据，预计 2026-10-22 新周期恢复后作为备用，不在本地流程中调用。启动入口是双击 `启动灵感回声.cmd`，默认打开 `http://localhost:3000`。

本地模式不需要登录。AI 相关按钮会根据本机是否配置 `OPENAI_API_KEY` 明确显示可用或暂不可用；记录、编辑、检索、闪卡、行动票和打卡不依赖 AI 服务。

## 使用方式

1. 双击 `启动灵感回声.cmd`，或运行 `npm run dev`。
2. 打开 `http://localhost:3000`，直接进入私人空间。
3. 在“记录”页保存想法；保存、编辑、删除和检索都写入本机 PGlite 数据库。
4. 在“账号与设置”里使用“导出完整备份”保存 JSON；换电脑时复制 `private-data/` 后再启动即可恢复。
5. Apple Watch 或备忘录中的文字可以直接粘贴到记录页；网站不会自动读取设备内容。

手机端可以在浏览器中使用，但不要更换访问地址：`APP_ORIGIN` 保留为 `http://localhost:3000`，这样写操作的来源校验与打开地址一致。

本地运行和数据迁移说明见 [docs/本地模式说明](./docs/本地模式说明.md)。腾讯云部署文件仍保留作备用配置；在额度恢复前不要执行发布或资源操作。

## 数据与 AI

数据含想法、来源、AI 整理和个人理解，全部位于本机 `private-data/pglite/`。服务端 API 仍使用版本校验，写入得到数据库确认后才返回成功。AI 只在主动点击整理时读取当前记录；未配置本机 AI 凭据时不会伪造结果。

AI 模型通过文字指令生成 JSON，服务端再严格检查结构和来源归属。权限、额度、超时、格式或写入失败均不会显示成功。本地模式不提供账号密码修改，因为没有登录账号。

备份不含会话、密钥或未保存草稿。单次恢复上限 4 MiB，导出目标约 3.5 MiB/份，必须保存并恢复全部分卷。

### 每日打卡

账号与设置中的打卡牌使用独立的 `echo_checkins` 表，首次启动时由本地 PGlite 自动应用 `supabase/migrations/` 下的三份迁移。数据库按北京时间划分日期，同一天只保存一条记录。

每日按数据库的北京时间（Asia/Shanghai）划分，同一账号每天只保存一条，重复点击保留首次内容。跨午夜的旧页面提交会要求刷新日期。累计天数只统计已保存日期；连续天数在今日尚未打卡时延续到昨天，漏掉完整一天后归零。心情最多 24 字、金句最多 100 字。预览页的打卡仅为页面内演示，不写入本地数据库；正式工作区的打卡会写入 `private-data/pglite/`。现有灵感集 JSON 备份不包含打卡记录。

## 生产验收

本地验收重点是：保存后刷新仍在、编辑后刷新仍在、删除后刷新确实消失、停止服务再启动后数据仍在，以及打卡可以读取和保存。未配置 AI 时，界面必须明确显示“AI 未配置”，不把本地模板结果冒充模型输出。

当前仍没有微信小程序、Watch 原生应用、备忘录自动同步、音频转写、全库问答、语义向量检索或离线正式保存队列。旧腾讯云与 Supabase 代码仅保留作兼容和历史参考，不是当前运行路径。
